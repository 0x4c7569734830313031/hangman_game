# Hangman Game

Un pequeño juego del **Ahorcado** hecho con **React + TypeScript**. Este proyecto fue creado siguiendo el curso de **Fernando Herrera**.

---

## 📌 Descripción

El juego muestra una palabra oculta y el usuario debe adivinarla letra por letra. Si se equivoca demasiadas veces, pierde.

Es un proyecto simple pensado para practicar:

* Componentes en React
* Estado y eventos
* TypeScript básico
* Vite

---

## ▶️ Ejecutar el proyecto

```bash
npm install
npm run dev
```

Abrir en el navegador:

```
http://localhost:5173/
```

---

## 📦 Build de producción

```bash
npm run build
```

Los archivos listos quedarán en la carpeta `dist/`.
